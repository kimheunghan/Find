"분명 그 문장이 들어간 한글 문서가 있었는데…"

보고서_최종.hwp, 보고서_최종(2).hwp, 보고서_진짜최종.hwp…
이름이 비슷한 파일이 쌓이면 결국 하나씩 열어 보게 됩니다. 이 글에서는 파일 이름이 아니라 파일 안의 내용으로 찾는 방법을 정리했습니다.

윈도우 파일 검색으로 안 찾아지는 이유

  • 탐색기 검색은 폴더를 하나씩 뒤져서 느립니다.
  • 한글(HWP) 문서 안의 글자는 한컴오피스 설치나 색인 설정에 따라 아예 못 읽는 경우가 많습니다.
  • 캡처한 이미지 속 글자, 메일 첨부파일 안의 내용은 검색 대상이 아닙니다.

에브리띵(Everything)과는 뭐가 다를까?

파일 찾기 프로그램으로 에브리띵을 많이 씁니다. 파일 이름을 아주 빠르게 찾아 주는 좋은 프로그램이고, 이름이 기억날 때는 그걸로 충분합니다. 문제는 이름은 기억 안 나고 내용만 기억날 때입니다.

이럴 때 쓰면 좋은 것
파일 이름이 기억난다에브리띵 같은 이름 검색 프로그램
안에 적힌 문장만 기억난다FindInside (파일 내용 검색)
캡처 이미지 속 글자로 찾고 싶다FindInside (이미지 글자 검색, OCR)
메일 첨부파일 안의 내용으로 찾고 싶다FindInside (메일·첨부파일 검색)

FindInside로 파일 내용 검색하는 법

[이미지] 검색창에 단어를 넣고 결과가 나온 화면
  1. 검색할 폴더를 고릅니다. "색인 시작"을 누르면 파일 이름·폴더 이름은 몇 분 안에 검색되고, 문서 내용과 이미지 속 글자는 뒤에서 차례로 읽습니다.
  2. 기억나는 단어 하나를 넣습니다. 예: "견적 단가", "서버 IP", "192.168"
  3. 결과에 위치가 나옵니다. "15쪽", "B7 셀", "슬라이드 3"처럼 어디에 있는지 보여 줍니다.
  4. 누르면 그 위치로 열립니다. 한글·워드·엑셀·파워포인트·PDF가 찾은 쪽·셀·슬라이드로 바로 열리고, 찾던 문구가 선택되어 있습니다.

💡 폴더 내 파일 내용 검색

특정 폴더 안에서만 찾고 싶으면 상세 조건 → 검색 범위 → 폴더 선택…으로 그 폴더를 고르면 됩니다. 확장자(HWP·XLSX·PDF 등)로 한 번 더 좁힐 수도 있습니다.

[이미지] 결과에 쪽 번호·셀 위치가 표시된 화면

무엇을 검색하나요?

📄 문서 안의 글자한글(HWP·HWPX), 엑셀(XLSX), PDF, 워드(DOCX), 파워포인트(PPTX), 텍스트·CSV
🖼️ 이미지 속 글자화면 캡처, 스캔 서류, 사진 (작은 글씨·세로쓰기도 읽음)
✉️ 메일과 첨부파일IMAP·POP3 메일(메일플러그, 네이버, 다음, Gmail 등)의 본문과 첨부 문서 내용, PC에 저장한 EML·MSG 파일
📁 파일 이름파일 이름·폴더 이름의 일부만 넣어도 찾음

알아 두면 좋은 점

  • 한컴오피스가 없어도 한글 문서 내용이 검색됩니다.
  • 한자로 적힌 이름(金英洙)도 한글(김영수)로 찾을 수 있습니다.
  • 파일이 새로 생기거나 바뀌면 저절로 반영됩니다.
  • 색인과 검색은 모두 내 PC 안에서 합니다. 파일 내용을 서버로 보내지 않습니다.

⚠️ 아직 안 되는 것

Microsoft 365처럼 IMAP이 막힌 회사 메일은 아직 연결할 수 없습니다. 암호가 걸린 한글 문서는 파일 이름으로만 찾습니다.
