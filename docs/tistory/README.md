# 티스토리 글 (hung6789.tistory.com)

HTML 파일은 **그대로 전부** 티스토리 HTML 모드에 붙여 넣는 본문이다 (안내 메모를 파일 안에 넣지 않는다 — 붙여 넣으면 글 원본에 남는다).

티스토리 스킨이 본문 `<p>` 글자색을 덮어쓰므로, 어두운 배경 위 글자에는 `color:#ffffff !important`처럼 **글자 요소마다 색을 직접** 준다.

- 태그: `파일검색, 파일찾기, 파일내용검색, 파일검색프로그램, 폴더내파일내용검색, 한글파일내용검색, 에브리띵, 문서검색, PC검색, FindInside`
