## 1. 넷리파이 리디렉션 — **2026-10-29 이후에만 가능**

판매 페이지를 Cloudflare Pages로 옮긴 뒤, 옛 Netlify 주소로 들어오는 사람을 새 주소로 넘긴다.

**먼저 확인할 것**: 오늘이 2026-10-29를 지났는가. Netlify 팀(`hung67890's team`)이 크레딧이 떨어져 그날까지 새 배포가 멈춰 있다. 기존 사이트는 계속 떠 있으니 급하지는 않다.

**할 일**: `_redirects`라는 **확장자 없는 파일** 하나만 든 폴더를 만들어 Netlify에 올린다. 내용은 한 줄:

```
/* https://findinside.pages.dev/:splat 301
```

`/*`는 모든 경로, `:splat`은 걸린 부분을 그대로 옮겨 붙이기, `301`은 영구 이전(구글이 검색 순위를 새 주소로 넘겨준다)이다.

**함정**: Netlify는 그 경로에 **파일이 있으면 리디렉션보다 파일을 먼저 내준다.** 그래서 기존 `index.html` 등이 올라가 있는 채로 `_redirects`만 더하면 소용없다. `_redirects` 하나만 든 폴더를 올려 기존 파일을 치우거나, `301!`처럼 느낌표를 붙여 강제한다. 앞쪽이 헷갈릴 일이 없다.

**올리는 곳**: app.netlify.com → `findinside` → Deploys 탭의 끌어다 놓는 칸. 이 업로드는 사람이 해야 한다.

넘어간 뒤 몇 달 지나 검색 결과가 새 주소로 다 바뀌면 Netlify 사이트를 지워도 된다.

## 2. Cloudflare Pages로 판매 페이지 옮기기 — **지금도 가능, 도메인 결정이 먼저**

Netlify는 크레딧이 떨어져 배포가 멈췄다. 사용자는 Cloudflare 계정(`jocbo.pages.dev` 운영 중)에 여유가 있어 그쪽으로 옮기기로 했다.

**먼저 사용자에게 물을 것**: 진짜 도메인(`findinside.com` 등)을 살 것인가, `findinside.pages.dev`로 갈 것인가. `pages.dev`로 갔다가 나중에 도메인을 사면 서치 콘솔·스토어·약관 주소를 **또** 고쳐야 한다. 2026-10-07 기준 아직 답을 못 받았다.

**Cloudflare Pages 설정** (저장소를 연결하면 푸시할 때마다 자동 배포된다. `site/`가 저장소에 그대로 들어 있어 빌드가 필요 없다):

| 항목 | 값 |
|---|---|
| 저장소 | `kimheunghan/Find` (비공개여도 됨) |
| 빌드 명령 | 비워 둠 |
| 빌드 출력 디렉터리 | `site` |

**저장소 안에서 고칠 주소 32군데** (`findinside.netlify.app` → 새 주소):

| 파일 | 개수 |
|---|---|
| `site/sitemap.xml` | 7 |
| `site/hwp-search.html`·`pdf-search.html`·`excel-search.html`·`ocr-search.html` | 각 5 (canonical, og:url, og:image, 이동 경로 표시 2) |
| `site/robots.txt` | 1 |
| `src/product.json` (website) | 1 |
| `README.md`, `docs/PC-MVP.md`, `docs/판매-등록-가이드.md` | 각 1 |

형식별 안내 4개와 `robots.txt`·`sitemap.xml`은 `npm run docs`가 만들어 내는 파일이 **아니라** `site/`에 직접 들어 있는 파일이다. 손으로 고쳐야 한다.

`src/product.json`의 주소는 앱 안 약관·개인정보 페이지에도 찍히므로 **다음 빌드(1.0.4)부터** 반영된다.

**구글 서치 콘솔**: 주소가 바뀌면 다른 사이트로 보므로 새 속성을 추가·확인하고 사이트맵(`<새주소>/sitemap.xml`)을 다시 제출한다. 확인용 `<meta name="google-site-verification">`은 `site/index.html`에 이미 있고 보통 계정 단위라 그대로 통과한다. 새 속성 화면에 다른 태그가 나오면 그걸로 바꾼다. **기존 netlify 속성은 지우지 않는다.**

**저장소 밖에서 사용자가 직접 고칠 곳**: Partner Center 목록의 웹사이트·지원 주소, Lemon Squeezy 가게 설정, `findinside-download` 저장소 README(이건 `gh`로 대신 고칠 수 있다).
