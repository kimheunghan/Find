# FindInside 판매 등록 가이드

앱에 들어간 것(1.0.0): 체험판 14일, Lemon Squeezy 라이선스 키 활성화·해제, 앱 아이콘, 이용약관·개인정보처리방침·오픈소스 고지(도움말 메뉴), 판매 페이지(`site/`).

아래는 직접 해야 하는 일입니다. 순서대로 하면 됩니다.

## 1. Lemon Squeezy 가게와 상품 만들기

1. https://app.lemonsqueezy.com 에서 가입하고 가게(Store)를 만듭니다. 판매자 정보는 개인(kimheunghan)으로 등록합니다.
2. **Products → New product**
   - 이름: FindInside
   - 가격: 1회 결제(Single payment). 정한 가격을 넣습니다.
   - **License keys** 켜기 → Activation limit **2**(약관·판매 페이지에 적힌 PC 수와 같게), 기간은 무제한(Never expires).
   - 파일: `release\Find_Setup.exe`를 올리면 구매 후 내려받기로 제공됩니다(체험판 링크와 같은 파일이어도 됩니다).
3. 상품을 저장한 뒤 다음 값을 확인합니다.
   - Store ID: Settings → Stores 목록의 숫자 ID
   - Product ID: 상품 화면 주소나 API의 숫자 ID
   - Checkout URL: 상품의 **Share** 버튼 → 결제 링크

## 2. `src/product.json` 채우기

```json
"price": "₩00,000",
"supportEmail": "문의 받을 이메일",
"website": "판매 페이지 주소 (예: https://findinside.pages.dev)",
"downloadUrl": "체험판 설치 파일 내려받기 주소",
"lemonSqueezy": { "storeId": 12345, "productId": 67890, "checkoutUrl": "https://....lemonsqueezy.com/buy/..." }
```

- `storeId`·`productId`를 넣어야 다른 가게·다른 상품의 키로 활성화하는 것을 막습니다. **비워 두면 Lemon Squeezy의 어떤 키로도 활성화됩니다.**
- 값을 바꾼 뒤 `npm run dist`를 실행하면 앱 안의 약관·방침과 `site/`가 새 값으로 다시 만들어집니다. 빈 값이 있으면 빌드 끝에 경고가 나옵니다.

## 3. 판매 페이지 올리기

`site/` 폴더를 그대로 올리면 됩니다(정적 파일). 저장소가 비공개라면 GitHub Pages 대신 다음 중 하나가 간단합니다.

- Cloudflare Pages 또는 Netlify: 가입 후 `site` 폴더를 끌어다 놓기 → 무료 주소(`*.pages.dev`, `*.netlify.app`) 발급
- 체험판 설치 파일(107MB)은 페이지와 함께 올리기에 커서, GitHub Releases(공개 저장소를 따로 만들어) 또는 Lemon Squeezy 상품 파일 링크를 `downloadUrl`로 씁니다.

판매 페이지 주소를 `website`에 넣고, Lemon Squeezy 가게 설정의 웹사이트에도 같은 주소를 넣습니다. 앱 화면 캡처 1~2장을 `web/`에 추가하면 심사와 판매에 도움이 됩니다(메일·파일 이름에 개인정보가 보이지 않게).

## 4. Lemon Squeezy 심사(Store activation) 신청

심사에서 보통 보는 것: 제품 설명, 가격, 환불 정책, 이용약관, 개인정보처리방침, 연락처가 있는 웹사이트. 모두 `site/`에 들어 있습니다(환불 14일은 이용약관 3조와 가격 안내에 있음).

## 5. 코드 서명 (권장)

지금 설치 파일은 서명이 없어 처음 실행할 때 Windows가 "PC를 보호했습니다" 경고를 띄웁니다("추가 정보 → 실행"으로 설치 가능).

- 인증서(OV 코드 서명)를 사면 `package.json`의 `build.win`에 인증서 설정을 넣어 빌드 때 자동 서명합니다. 인증서를 받으면 알려 주세요.
- 또는 Microsoft Store에 올리면 스토어가 서명해 줍니다(설치 형식을 MSIX로 바꾸는 작업 필요).

## 6. 판매 전 마지막 확인

- [ ] `npm run dist` 끝에 "판매용이 아닌 시험 빌드" 경고가 없는지
- [ ] Lemon Squeezy **테스트 모드**에서 구매 → 받은 키로 앱 활성화 → "이 PC에서 해제" → 다른 PC에서 활성화
- [ ] 테스트 모드에서 환불 → 앱을 다시 켜면(7일마다 확인) 라이선스가 풀리는지 (Lemon Squeezy에서 키를 Disable 해 보면 바로 확인 가능)
- [ ] 판매 페이지의 구매·내려받기 버튼, 이용약관·개인정보처리방침 링크
- [ ] 이용약관·개인정보처리방침은 일반적인 내용으로 만든 초안입니다. 판매 전에 한 번 읽어 보고, 필요하면 전문가 검토를 받으세요.

- 체험 기간·라이선스 상태는 암호화해 두 곳(`%APPDATA%\findinside`, `%LOCALAPPDATA%\FindInside`)에 저장합니다. 시계를 되돌려도 체험 기간이 늘어나지 않습니다.
