# FindInside PC 앱 MVP

## 이번 단계의 목적

Windows 사용자가 검색 위치를 선택하고, 해당 위치의 파일명·폴더명·전체 경로를 빠르게 검색할 수 있는 첫 실행 가능한 앱을 만든다.

## 포함 기능

- 여러 검색 폴더 선택
- 기본 시스템·개발 폴더 제외
- 검색 위치와 제외 폴더를 화면에서 추가·삭제
- 파일명, 폴더명, 전체 경로 색인
- 여러 단어와 정확 문구 검색
- 검색 관련도 정렬
- 파일 열기와 폴더에서 위치 확인
- 색인 결과를 사용자 PC에 저장
- 재색인을 통한 신규·수정·삭제 항목 반영

## 다음 단계

1. Windows 파일 변경 감지를 이용한 자동 증분 색인
2. TXT, CSV, PDF, DOCX, XLSX, PPTX 내부 텍스트 추출
3. 검색 결과의 문서 내부 위치와 미리보기
4. HWP/HWPX 파서 기술 검증
