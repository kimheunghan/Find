# 홍보 글 초안 (2026-10-10)

복사해서 붙여 넣는 용도. 기능 설명은 판매 페이지·앱에서 확인된 것만 썼다. 후기·숫자는 지어내지 않았다 — 실제 사용 경험이 생기면 그걸로 바꾸면 더 좋다.

- 링크는 **netlify.app 한 곳으로 모은다** (구글에 이미 올라가 있고, 링크를 한 주소로 모아야 검색 순위가 오른다).
- `[이미지: …]`는 앱 화면을 캡처해 넣을 자리.
- 블로그 글은 하루에 하나씩 나눠 올리는 게 좋다 (한 번에 몰아 올리면 네이버가 광고성으로 볼 수 있다).

## 1. 네이버 블로그 글

### 글 1 — 한글 파일 내용 검색

**제목**
```
폴더 안 한글(HWP) 파일, 내용으로 찾는 방법 — 파일 이름이 기억 안 날 때
```

**본문**
```
"분명 그 문장 들어간 한글 문서가 있었는데…"
보고서_최종.hwp, 보고서_최종(2).hwp, 보고서_진짜최종.hwp…
이름이 비슷한 파일이 쌓이면 하나씩 열어 보는 수밖에 없습니다.

윈도우 탐색기 검색으로 한글 파일 내용을 찾으려 해도
한컴오피스 설치나 색인 설정에 따라 HWP 안의 글자를 못 읽는 경우가 많습니다.

그래서 직접 만든 프로그램이 FindInside입니다.

[이미지: 검색창에 단어를 넣고 한글 파일이 결과로 나온 화면]

■ 이렇게 찾습니다
1. 검색할 폴더를 고르고 "색인 시작"을 누릅니다.
   파일 이름은 몇 분 안에 검색되고, 문서 내용은 뒤에서 차례로 읽습니다.
2. 기억나는 단어 하나를 검색창에 넣습니다.
3. 결과에 "15쪽"처럼 그 문장이 있는 쪽 번호가 나옵니다.
4. 누르면 한글에서 그 쪽으로 바로 열리고, 찾던 문구가 선택되어 있습니다.

[이미지: 결과에 쪽 번호가 나온 화면]

■ 이런 점이 편합니다
- 한컴오피스가 없는 PC에서도 HWP·HWPX 내용이 검색됩니다.
- 표 안에 적힌 글자도 찾습니다.
- 한자로 적힌 이름(金英洙)도 한글(김영수)로 찾을 수 있습니다.
- 특정 폴더 안의 파일만 좁혀서 찾을 수도 있습니다.
  (상세 조건 → 검색 범위 → 폴더 선택)
- 엑셀·PDF·워드·파워포인트도 같은 검색창에서 함께 찾습니다.

■ 파일이 밖으로 나가지 않나요?
색인과 검색은 모두 내 PC 안에서 합니다. 파일 내용을 서버로 보내지 않습니다.

■ 써 보기
Windows 10·11에서 14일 동안 무료로 모든 기능을 써 볼 수 있습니다. 카드 등록은 없습니다.
Microsoft Store에서 "FindInside"를 검색하거나 아래 페이지에서 받을 수 있습니다.

👉 https://findinside.netlify.app/hwp-search
```

**태그**
```
#한글파일내용검색 #HWP검색 #한글문서검색 #폴더내파일내용검색 #파일내용검색 #파일찾기 #문서검색프로그램 #한컴오피스 #업무효율 #FindInside
```

### 글 2 — 메일 첨부파일 내용 검색

**제목**
```
메일 첨부파일 '내용'까지 검색하는 방법 (네이버·다음·메일플러그·Gmail)
```

**본문**
```
"지난달에 받은 견적서에 그 금액이 있었는데…"
메일함 검색은 제목·보낸 사람·본문까지만 찾아 줍니다.
첨부된 한글·엑셀·PDF 안에만 있는 글자는
첨부를 하나씩 내려받아 열어 봐야 하죠.

FindInside는 메일을 연결해 두면
메일 본문과 첨부 문서 안의 글자까지 미리 읽어 둡니다.

[이미지: 메일 탭에서 첨부파일 내용이 검색된 화면]

■ 이렇게 찾습니다
- 메일 본문, 제목, 보낸 사람으로 검색
- 첨부된 한글(HWP)·엑셀·PDF·워드 문서 안의 글자로 검색
- 첨부 이미지 속 글자도 읽어서 검색
- 받은편지함·보낸 편지함별로 좁혀 보기
- 찾은 메일은 프로그램 안에서 바로 보고, 첨부는 찾은 쪽으로 바로 열기

■ 연결할 수 있는 메일
IMAP 또는 POP3를 지원하는 메일 — 메일플러그, 네이버, 다음, Gmail 등
(서비스에 따라 앱 비밀번호가 필요합니다.
Microsoft 365처럼 IMAP이 막힌 회사 메일은 아직 연결되지 않습니다.)

■ PC에 저장한 메일 파일도
아웃룩에서 저장한 .msg, .eml 파일도 폴더를 색인하면 본문·첨부까지 검색됩니다.

■ 비밀번호·메일은 안전한가요?
메일 비밀번호는 내 PC에 Windows 암호화로 저장하고 어떤 서버로도 보내지 않습니다.
메일 원본을 PC에 쌓아 두지 않고, 검색에 필요한 글자만 색인합니다.

■ 써 보기
14일 무료 체험 · 카드 등록 없음 · Windows 10·11

👉 https://findinside.netlify.app/mail-search
```

**태그**
```
#메일검색 #메일본문검색 #첨부파일검색 #메일첨부파일 #이메일검색 #메일플러그 #네이버메일 #업무메일 #파일내용검색 #FindInside
```

### 글 3 — 이름 말고 내용으로 파일 찾기 (파일 찾기 프로그램)

**제목**
```
파일 이름이 기억 안 날 때, '내용'으로 파일 찾는 프로그램
```

**본문**
```
파일 찾기 프로그램이라고 하면 보통 에브리띵(Everything)을 많이 씁니다.
파일 이름을 아주 빠르게 찾아 주는 좋은 프로그램이고,
이름이 기억날 때는 그걸로 충분합니다.

그런데 이런 때가 있죠.
- 파일 이름은 전혀 기억 안 나고, 안에 적힌 문장만 생각날 때
- 캡처해 둔 화면 속 글자로 찾고 싶을 때
- 메일 첨부로 받은 문서 안의 내용으로 찾고 싶을 때

이럴 때 쓰려고 만든 게 FindInside입니다.

[이미지: 한 검색창에 파일·이미지·메일 결과가 함께 나온 화면]

■ 무엇을 검색하나요
- 파일 이름·폴더 이름
- 문서 안의 글자: 한글(HWP·HWPX), 엑셀, PDF, 워드, 파워포인트, 텍스트
  → 결과에 "15쪽", "B7 셀", "슬라이드 3"처럼 위치가 나오고, 누르면 그 위치로 열립니다.
- 이미지 속 글자: 화면 캡처, 스캔 서류, 사진 (OCR)
- 메일 본문과 첨부파일

■ 어떻게 빨리 찾나요
고른 폴더를 미리 '색인'해 둡니다.
파일 이름은 처음 몇 분이면 검색되고, 문서 내용과 이미지 글자는 뒤에서 차례로 읽습니다.
파일이 새로 생기거나 바뀌면 저절로 반영됩니다.

■ 정리하면
이름을 알면 → 에브리띵 같은 이름 검색 프로그램
내용만 기억나면 → FindInside

■ 써 보기
14일 무료 체험 · 카드 등록 없음 · 파일은 내 PC 밖으로 나가지 않음

👉 https://findinside.netlify.app/file-search
```

**태그**
```
#파일찾기 #파일검색 #파일검색프로그램 #파일내용검색 #에브리띵 #Everything #PC검색 #문서검색 #OCR #FindInside
```

## 2. 커뮤니티 소개 글

올리기 전에 **그 게시판의 홍보 규칙**을 꼭 확인한다 (자작 프로그램 소개를 허용하는 게시판인지, 링크를 넣어도 되는지, 하루 몇 개까지인지). 같은 글을 여러 곳에 한꺼번에 올리지 않는다.

**제목**
```
[자작] 한글·엑셀·PDF 파일 '내용'으로 찾는 윈도우 프로그램을 만들었습니다
```

**본문**
```
안녕하세요. 혼자 만든 윈도우 프로그램을 소개드립니다.

회사에서 한글 문서가 쌓이다 보니
"그 문장 들어간 파일이 뭐였지?" 하며 파일을 하나씩 여는 일이 많았습니다.
윈도우 검색은 HWP 안의 글자를 잘 못 찾고,
에브리띵은 파일 이름만 찾아서 직접 만들게 됐습니다.

■ FindInside가 하는 일
- 파일 이름뿐 아니라 문서 안의 글자로 검색
  (한글 HWP·HWPX, 엑셀, PDF, 워드, 파워포인트)
- 결과에 몇 쪽 / 어느 셀 / 몇 번째 슬라이드인지 표시, 누르면 그 위치로 열림
- 캡처·스캔 이미지 속 글자 검색 (OCR)
- 회사 메일(IMAP·POP3) 연결 시 메일 본문·첨부파일 내용까지 검색
- 한컴오피스 없이도 HWP 내용 검색
- 색인·검색 모두 PC 안에서만 (파일을 서버로 보내지 않음)

■ 조건
- Windows 10·11 (64비트)
- 14일 무료 체험 (카드 등록 없음)
- 정식판 29,000원 · PC 2대 · 1.x 업데이트 무료 · 14일 환불

Microsoft Store에서 "FindInside"로 검색하시면 경고 없이 설치됩니다.
자세한 내용: https://findinside.netlify.app

아직 부족한 점이 많습니다.
써 보시고 불편한 점이나 원하는 기능을 알려 주시면 다음 버전에 반영하겠습니다.
(Microsoft 365처럼 IMAP이 막힌 메일은 아직 연결이 안 됩니다.)
```

**어디에 올릴지 (예시, 규칙 확인 필요)**
- 클리앙 — 자작 프로그램 소개가 허용되는 게시판
- 뽐뿌 — 소프트웨어 관련 게시판
- 공무원·행정·회계·사무직 카페 — 한글 문서를 많이 쓰는 곳 (카페마다 홍보 규칙이 엄격하니 운영진 확인)
