FindInside 개인정보처리방침

시행일: 2026-10-01 · 개정: 2026-11-30

운영: 흥한소프트(K Software), 대표 김흥한(Kim Heunghan)

FindInside는 사용자의 파일, 문서, 이미지, 메일, 검색어를 개발자나 다른 곳으로 보내지 않습니다. 색인과 검색은 모두 사용자 PC 안에서 이루어집니다.

1. 개발자가 받는 정보

프로그램 사용 중 개발자가 받는 정보는 라이선스 확인에 필요한 것(아래 2번 표)뿐입니다. 사용 통계, 광고, 오류 자동 전송 기능이 없습니다.

결제는 결제 화면에 표시된 판매 대행자(Merchant of Record)인 Paddle.com 또는 Lemon Squeezy가 처리합니다. 결제에 필요한 정보(이름, 이메일, 결제 수단, 청구 국가 등)는 판매 대행자가 받으며 각자의 개인정보처리방침(Paddle, Lemon Squeezy)을 따릅니다. 카드 번호 등 결제 정보는 개발자에게 전달되지 않습니다.

Paddle.com으로 결제한 경우, 결제가 끝나면 개발자의 라이선스 서버가 판매 대행자에게서 구매자 이메일, 이름, 주문 번호를 받아 라이선스 키와 함께 보관하고, 개발자의 Gmail 계정(Google)으로 키 안내 메일을 보냅니다. Lemon Squeezy로 결제한 경우에는 개발자가 Lemon Squeezy 판매 관리 화면에서 같은 주문 내역을 봅니다. 이 정보는 라이선스 확인, 키 다시 보내기, 환불, 문의 응대에만 씁니다.

2. 인터넷으로 보내는 정보

받는 곳언제보내는 정보
라이선스 서버 — 개발자의 라이선스 서버(jocbo.pages.dev, Cloudflare) 또는 Lemon Squeezy(api.lemonsqueezy.com). 프로그램 판에 따라 다릅니다.라이선스 키를 입력할 때, 이후 약 7일마다, "이 PC에서 해제"를 누를 때라이선스 키, 이 설치를 구분하는 임의의 이름(예: "FindInside 1a2b3c4d"). PC 이름·사용자 이름·파일 정보는 보내지 않습니다.
업데이트 확인 — FindInside 홈페이지(findinside.netlify.app, findinside.pages.dev)
(홈페이지의 설치 파일로 설치한 1.0.7 이상만. Microsoft Store판은 Store가 업데이트합니다.)		프로그램을 실행한 날 하루 한 번, 사용자가 [지금 업데이트]를 선택할 때최신 버전 정보 요청과 설치 파일 내려받기 요청뿐입니다. 라이선스 키·PC 정보·파일 정보는 보내지 않습니다.
사용자가 직접 등록한 메일 서버
(IMAP·POP3)		메일 계정을 연결하거나 새 메일을 가져올 때(약 15분마다), 메일을 열 때사용자가 입력한 아이디와 비밀번호(앱 비밀번호). 메일 서버에서 메일을 받아 오기만 하고, 메일을 지우거나 보내지 않습니다.

인터넷 통신에서는 기술적으로 사용자의 IP 주소가 상대 서버에 전달됩니다.

3. 사용자 PC에 저장하는 정보

내용위치
파일 목록, 문서·이미지·메일에서 뽑은 글자(검색용 색인), 설정%APPDATA%\findinside
메일 계정 비밀번호 — Windows 데이터 보호(DPAPI)로 암호화해 이 PC의 이 Windows 사용자만 풀 수 있음%APPDATA%\findinside\findinside-secrets.json
라이선스·체험 기간 상태 — 암호화해 저장%APPDATA%\findinside, %LOCALAPPDATA%\FindInside

메일 원문은 저장하지 않고, 검색에 필요한 글자와 제목·보낸 사람·날짜 같은 목록 정보만 저장합니다. 메일을 열 때 메일 서버에서 다시 받습니다.

4. 제3자 제공과 처리 위탁

개발자는 사용자의 정보를 제3자에게 제공하지 않습니다. 다음 업체가 개발자를 대신해 일부를 처리합니다(국외 이전 포함).

  • Paddle.com Market Limited(영국), Lemon Squeezy, LLC(미국): 결제, 세금, 영수증, 환불 — 구매할 때 구매자가 직접 입력하는 정보
  • Cloudflare, Inc.(미국): 라이선스 서버 운영 — 라이선스 키, 설치 이름, 구매자 이메일·이름·주문 번호
  • Netlify, Inc.(미국), Cloudflare, Inc.(미국): 홈페이지와 업데이트 확인 파일 제공 — 접속 시 전달되는 IP 주소
  • Google LLC(미국, Gmail): 라이선스 키 안내 메일 발송 — 구매자 이메일, 이름, 라이선스 키

5. 보관 기간과 삭제

  • PC에 저장한 정보는 사용자가 지울 때까지 남습니다. 프로그램에서 메일 계정을 삭제하면 그 계정의 색인과 비밀번호도 지웁니다.
  • 모두 지우려면 프로그램을 제거한 뒤 위 표의 폴더를 삭제하세요.
  • 라이선스 서버의 정보는 라이선스가 유효한 동안 보관합니다. "이 PC에서 해제"를 누르면 그 PC의 등록 기록을 지웁니다.
  • 주문 정보는 관련 법령(전자상거래법 등)이 정한 기간 동안 판매 대행자가 보관합니다. 삭제를 원하면 아래 문의처로 요청하세요.

6. 사용자의 권리

사용자는 개발자가 가진 자신의 주문·라이선스 정보에 대해 열람, 정정, 삭제, 처리 정지를 요청할 수 있습니다. 아래 문의처로 요청하면 지체 없이 처리합니다.

Privacy Policy (English summary)

Effective 2026-10-01 · Revised 2026-11-30. Operated by 흥한소프트 (K Software), Kim Heunghan.

FindInside indexes and searches files, documents, images and mail only on the user's own PC. We never receive file contents, mail, search terms or usage data, and the program sends no telemetry.

License activation, a check about every 7 days and deactivation send the license key and a random installation name (for example "FindInside 1a2b3c4d") to our license server at jocbo.pages.dev (Cloudflare) or to Lemon Squeezy, depending on the program version. Version 1.0.7 and later installed from our website check our website (findinside.netlify.app) once a day for a newer version; this request carries no license key, PC or file information. Connecting a mail account sends the user's login only to the mail server the user entered.

Payments are handled by the Merchant of Record shown on the checkout, Paddle.com or Lemon Squeezy; we never receive card details. After a purchase through Paddle.com our license server keeps the buyer's email, name and order number with the license key, and sends the key by email from our Gmail account (Google). We use this only for license checks, key resends, refunds and support, and keep it while the license is valid. Ask us to see, correct or delete it at any time.
