PC 파일 찾기, 이름이 기억 안 나도

파일 이름·폴더 이름으로 찾는 건 기본입니다. 이름이 생각나지 않으면 파일 안에 적힌 글자로 찾습니다. 한글·엑셀·PDF·워드 문서, 이미지 속 글자, 메일 첨부파일까지 한 검색창에서.

윈도우 파일 검색이 느리거나 안 찾아질 때

윈도우 탐색기에서 파일을 찾으면 폴더를 하나씩 뒤지느라 오래 걸리고, 문서 안의 글자는 색인 설정이나 프로그램 설치 여부에 따라 아예 안 찾아지기도 합니다. "보고서_최종(3).hwp"처럼 비슷한 이름이 쌓이면 이름만으로는 원하는 파일을 고를 수도 없습니다.

FindInside는 고른 폴더를 미리 색인해 둡니다. 파일 이름·폴더 이름·경로는 처음 몇 분이면 검색되고, 문서 내용과 이미지 속 글자는 뒤에서 차례로 읽어 읽은 파일부터 바로 검색됩니다. 파일이 새로 생기거나 바뀌고 지워지면 저절로 반영됩니다.

이렇게 찾습니다

  • 파일 이름·폴더 이름의 일부만 넣어도 찾습니다.
  • 이름이 기억 안 나면 문서 안의 단어로 찾습니다 — 한글(HWP·HWPX), 엑셀, PDF, 워드, 파워포인트, 텍스트.
  • 화면 캡처·스캔 서류·사진 속 글자로도 찾습니다 (OCR).
  • 회사 메일을 연결하면 메일과 첨부파일도 같은 검색창에서 찾습니다.
  • 결과를 누르면 파일이 열리거나 폴더에서 바로 보여 줍니다. 문서는 찾은 쪽·셀·슬라이드로 열립니다.

폴더 내 파일 내용 검색

특정 폴더 안의 파일만 내용으로 찾고 싶으면, 상세 조건의 검색 범위 → 폴더 선택…으로 그 폴더를 고릅니다. 고른 폴더(하위 폴더 포함) 안의 파일 이름과 문서 내용만 검색되고, 여러 폴더를 함께 고를 수도 있습니다. 확장자(HWP·XLSX·PDF 등)로 한 번 더 좁힐 수 있습니다.

자주 묻는 질문

에브리띵(Everything, 에브리싱)과 무엇이 다른가요?

에브리띵은 파일 이름을 아주 빠르게 찾아 주는 프로그램입니다. 파일 이름이 기억날 때는 그것으로 충분합니다. FindInside는 파일 이름에 더해 문서 안의 글자, 이미지 속 글자, 메일과 첨부파일까지 색인해 둡니다. 이름은 모르고 내용만 기억날 때 찾을 수 있습니다.

윈도우 기본 검색과 무엇이 다른가요?

윈도우 검색은 한글(HWP) 문서나 이미지 속 글자를 읽지 못하는 경우가 많습니다. FindInside는 HWP·HWPX를 직접 읽고(한컴오피스 없이도), 이미지 글자도 읽어 두며, 결과에 몇 쪽·어느 셀인지 보여 줍니다.

PC 전체를 검색하나요?

검색할 폴더(또는 드라이브)를 고르고, 빼고 싶은 폴더는 제외할 수 있습니다. 고른 범위 안의 파일을 색인합니다.

내 파일이 인터넷으로 나가나요?

아니요. 색인과 검색은 모두 내 PC 안에서 합니다. 파일 내용을 서버로 보내지 않습니다.
