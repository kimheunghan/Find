윈도우 검색으로는 안 찾아지던 것들

윈도우 탐색기 검색은 주로 파일 이름으로 찾고, 내용 검색은 색인 설정과 설치된 프로그램에 따라 되다 안 되다 합니다. 제목이 기억나지 않거나, 내용이 한글 파일·첨부파일·캡처 이미지 안에 있으면 찾기 어렵습니다.

무엇을 검색하나요

문서 안의 글자

HWP·HWPX·DOCX·XLSX·PPTX·PDF·TXT·CSV. 결과에 "15쪽", "B7 셀", "슬라이드 3"처럼 위치가 나오고, 누르면 문서가 열리며 찾을 문구가 복사됩니다.

이미지 속 글자

화면 캡처, 스캔 서류, 사진 속 글자를 읽어 둡니다. 작은 글씨와 세로쓰기도 읽습니다.

메일과 첨부파일

회사 메일(IMAP·POP3)을 연결하면 제목, 보낸 사람, 본문, 첨부 문서 내용까지 검색합니다. 받은편지함·보낸 편지함별로 좁혀 볼 수 있습니다.

알아서 최신 상태로

새로 만들거나 고친 파일은 자동으로 반영합니다. 결과는 관련도순·최신순으로 보고, 폴더와 확장자로 좁힐 수 있습니다.

쓰는 방법은 세 단계

  1. 설치하고 폴더 고르기검색할 드라이브나 폴더를 고르고 "색인 시작"을 누릅니다.
  2. 기다리지 않고 바로 검색파일 목록은 몇 분이면 만들어지고, 문서와 이미지 내용은 뒤에서 읽는 대로 검색에 반영됩니다.
  3. 기억나는 말로 찾기문장 일부, 숫자, 사람 이름 무엇이든 입력하면 문서·이미지·메일에서 함께 찾아 줍니다.

회사 자료도 안심하고

모든 색인과 검색은 내 PC 안에서만 합니다.

  • 파일·메일 내용을 인터넷으로 보내지 않습니다. 클라우드 업로드가 없습니다.
  • 사용 기록 수집, 광고, 자동 오류 전송이 없습니다.
  • 메일 비밀번호는 윈도우 암호화(DPAPI)로 이 PC에만 저장합니다.
  • 파일은 읽기만 하고 고치거나 지우지 않습니다. 메일도 서버에서 지우지 않습니다.

자주 묻는 질문

어떤 윈도우에서 쓸 수 있나요?

Windows 10, Windows 11 (64비트)에서 쓸 수 있습니다. 이미지 글자 읽기는 윈도우에 들어 있는 한국어 글자 인식 기능을 씁니다.

처음 설치하면 바로 검색되나요?

검색할 폴더를 고르고 "색인 시작"을 누르면 파일 이름은 몇 분 안에 검색됩니다. 문서 내용과 이미지 글자는 뒤에서 차례로 읽고, 읽은 파일부터 바로 검색됩니다.

회사 메일도 연결되나요?

IMAP 또는 POP3를 지원하는 메일(메일플러그, 네이버, 다음, Gmail 등)을 연결할 수 있습니다. 서비스에 따라 앱 비밀번호가 필요합니다. Microsoft 365처럼 IMAP이 막힌 회사 메일은 지금은 연결할 수 없습니다.

PC가 느려지지 않나요?

내용 읽기는 낮은 우선순위로 뒤에서 하고, 한 번 읽은 파일은 바뀌지 않는 한 다시 읽지 않습니다.

PC를 바꾸면 어떻게 하나요?

쓰던 PC에서 도움말 → 라이선스 → "이 PC에서 해제"를 누른 뒤, 새 PC에서 같은 키를 입력하면 됩니다.

환불은 어떻게 하나요?

구매 후 14일 안에 구매 확인 메일의 링크나 아래 문의처로 요청하시면 전액 환불해 드립니다.
