FindInside 개인정보처리방침

시행일: 2026-10-01

FindInside는 사용자의 파일, 문서, 이미지, 메일, 검색어를 개발자나 다른 곳으로 보내지 않습니다. 색인과 검색은 모두 사용자 PC 안에서 이루어집니다.

1. 개발자가 수집하는 정보

프로그램 사용 중 개발자가 받는 정보는 없습니다. 사용 통계, 광고, 오류 자동 전송 기능이 없습니다.

구매할 때에는 판매 대행사 Lemon Squeezy가 결제에 필요한 정보(이름, 이메일, 결제 수단, 청구 국가 등)를 처리합니다. 이 정보는 Lemon Squeezy 개인정보처리방침에 따라 처리되며, 개발자는 판매 관리 화면에서 주문 내역(구매자 이름·이메일·주문 번호)을 볼 수 있습니다. 개발자는 이를 라이선스 확인, 환불, 문의 응대에만 씁니다.

2. 인터넷으로 보내는 정보

받는 곳언제보내는 정보
Lemon Squeezy 라이선스 서버
(api.lemonsqueezy.com)		라이선스 키를 입력할 때, 이후 약 7일마다, "이 PC에서 해제"를 누를 때라이선스 키, 이 설치를 구분하는 임의의 이름(예: "FindInside 1a2b3c4d"). PC 이름·사용자 이름·파일 정보는 보내지 않습니다.
사용자가 직접 등록한 메일 서버
(IMAP·POP3)		메일 계정을 연결하거나 새 메일을 가져올 때(약 15분마다), 메일을 열 때사용자가 입력한 아이디와 비밀번호(앱 비밀번호). 메일 서버에서 메일을 받아 오기만 하고, 메일을 지우거나 보내지 않습니다.

인터넷 통신에서는 기술적으로 사용자의 IP 주소가 상대 서버에 전달됩니다.

3. 사용자 PC에 저장하는 정보

내용위치
파일 목록, 문서·이미지·메일에서 뽑은 글자(검색용 색인), 설정%APPDATA%\findinside
메일 계정 비밀번호 — Windows 데이터 보호(DPAPI)로 암호화해 이 PC의 이 Windows 사용자만 풀 수 있음%APPDATA%\findinside\findinside-secrets.json
라이선스·체험 기간 상태 — 암호화해 저장%APPDATA%\findinside, %LOCALAPPDATA%\FindInside

메일 원문은 저장하지 않고, 검색에 필요한 글자와 제목·보낸 사람·날짜 같은 목록 정보만 저장합니다. 메일을 열 때 메일 서버에서 다시 받습니다.

4. 제3자 제공과 처리 위탁

개발자는 사용자의 정보를 제3자에게 제공하지 않습니다. 결제와 라이선스 발급은 Lemon Squeezy(미국)가 처리합니다(국외 이전: 구매할 때 구매자가 Lemon Squeezy에 직접 입력하는 정보).

5. 보관 기간과 삭제

  • PC에 저장한 정보는 사용자가 지울 때까지 남습니다. 프로그램에서 메일 계정을 삭제하면 그 계정의 색인과 비밀번호도 지웁니다.
  • 모두 지우려면 프로그램을 제거한 뒤 위 표의 폴더를 삭제하세요.
  • 주문 정보는 관련 법령(전자상거래법 등)이 정한 기간 동안 Lemon Squeezy가 보관합니다. 삭제를 원하면 아래 문의처로 요청하세요.
