문서 내용 검색

HWP, HWPX, DOCX, XLSX, PPTX, PDF, TXT, CSV 안의 글자를 검색합니다. "12쪽", "Sheet1 B7", "슬라이드 3"처럼 어디에 있는지 바로 보여 주고, 누르면 문서가 열리고 찾을 문구가 복사됩니다.

이미지 속 글자

화면 캡처, 스캔한 서류, 사진 속 글자를 읽어 검색합니다. 작은 글씨, 세로쓰기, 한자 이름도 한글 음으로 찾을 수 있습니다.

메일과 첨부파일

회사 메일(IMAP·POP3)을 연결하면 제목, 보낸 사람, 본문은 물론 첨부된 한글·엑셀·PDF 문서 내용까지 검색합니다. 받은편지함·보낸 편지함별로 좁혀 볼 수 있습니다.

빠르고 가볍게

백만 개가 넘는 파일에서도 보통 1초 안팎으로 찾습니다. 새로 만든 파일과 바뀐 파일은 자동으로 반영하고, 최신순·관련도순으로 정렬할 수 있습니다.

내 파일은 내 PC 밖으로 나가지 않습니다

  • 색인과 검색은 모두 PC 안에서 합니다. 클라우드 업로드가 없습니다.
  • 사용 통계·광고·자동 오류 전송이 없습니다.
  • 메일 비밀번호는 Windows 데이터 보호(DPAPI)로 암호화해 이 PC에만 저장합니다.
  • 파일을 읽기만 하고, 고치거나 지우지 않습니다. 메일도 서버에서 지우지 않습니다.

자주 묻는 질문

어떤 Windows에서 쓸 수 있나요?

Windows 10, Windows 11 (64비트)에서 쓸 수 있습니다. 이미지 글자 읽기는 Windows에 들어 있는 한국어 OCR을 씁니다.

처음 설치하면 바로 검색되나요?

검색할 폴더를 고르고 "색인 시작"을 누르면 파일 목록은 몇 분 안에 만들어지고, 문서 내용과 이미지 글자는 뒤에서 차례로 읽습니다. 읽은 파일부터 바로 검색됩니다.

회사 메일도 연결되나요?

IMAP 또는 POP3를 지원하는 메일(메일플러그, 네이버, 다음, Gmail 등)을 연결할 수 있습니다. 서비스에 따라 앱 비밀번호가 필요합니다. Microsoft 365처럼 IMAP이 막힌 회사 메일은 지금은 연결할 수 없습니다.

PC를 바꾸면 어떻게 하나요?

쓰던 PC에서 도움말 → 라이선스 → "이 PC에서 해제"를 누른 뒤, 새 PC에서 같은 키를 입력하면 됩니다.
