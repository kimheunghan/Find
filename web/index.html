사용 방법 — 내려받기부터 구매까지

먼저 14일 동안 무료로 써 보고, 마음에 들면 구매해서 라이선스 키를 넣으면 됩니다.

  1. 체험판 설치 Microsoft Store에서 받기를 누르면 설치됩니다. 스토어를 쓸 수 없으면 {{SETUP_FILE}}를 받아 실행합니다. 새 프로그램이라 경고가 뜰 수 있습니다. Edge에서 "일반적으로 다운로드되지 않습니다"가 뜨면 ⋯ → 유지 → 그래도 계속, 실행할 때 "PC를 보호했습니다"가 뜨면 추가 정보 → 실행을 누르세요.
  2. 폴더 고르고 색인 시작 왼쪽 "검색 위치"에 찾을 드라이브나 폴더를 넣고 색인 시작을 누릅니다. 메일은 "메일 계정 추가"로 연결합니다.
  3. {{TRIAL_DAYS}}일 무료로 사용 모든 기능을 그대로 씁니다. 검색 결과의 "15쪽" 같은 줄을 누르면 문서가 그 쪽으로 바로 열립니다. 화면 위에 "체험판 · N일 남음"이 보입니다.
  4. 구매하기 앱의 구매하기 버튼이나 이 페이지의 구매 버튼을 누르면 결제 페이지가 열립니다. 카드 또는 PayPal로 결제합니다.
  5. 라이선스 키 받기 결제 완료 화면과 구매 확인 메일에 라이선스 키(예: A1B2C3D4-E5F6-…)가 나옵니다.
  6. 앱에 키 넣기 앱 위쪽의 라이선스 키 입력(또는 메뉴 도움말 → 라이선스)을 눌러 키를 붙여 넣고 활성화를 누르면 끝입니다. 체험 때 만든 색인은 그대로 이어서 씁니다.

회사 자료도 안심하고

모든 색인과 검색은 내 PC 안에서만 합니다.

  • 파일·메일 내용을 인터넷으로 보내지 않습니다. 클라우드 업로드가 없습니다.
  • 사용 기록 수집, 광고, 자동 오류 전송이 없습니다.
  • 메일 비밀번호는 윈도우 암호화(DPAPI)로 이 PC에만 저장합니다.
  • 메일을 볼 때 메일 속 바깥 이미지를 불러오지 않아, 메일을 열었는지 보낸 쪽에 알려지지 않습니다.
  • 파일은 읽기만 하고 고치거나 지우지 않습니다. 메일도 서버에서 지우지 않습니다.

자주 묻는 질문

에브리띵(Everything) 같은 파일 찾기 프로그램과 무엇이 다른가요?

에브리띵은 파일 이름을 아주 빠르게 찾아 주는 프로그램입니다. FindInside도 파일 이름·폴더 이름으로 찾고, 여기에 더해 문서 안의 글자, 이미지 속 글자, 메일과 첨부파일까지 색인해 둡니다. 파일 이름은 기억 안 나고 내용만 기억날 때 찾을 수 있습니다. PC 파일 찾기 자세히 →

어떤 윈도우에서 쓸 수 있나요?

Windows 10, Windows 11 (64비트)에서 쓸 수 있습니다. 이미지 글자 읽기는 윈도우에 들어 있는 한국어 글자 인식 기능을 씁니다.

처음 설치하면 바로 검색되나요?

검색할 폴더를 고르고 "색인 시작"을 누르면 파일 이름은 몇 분 안에 검색됩니다. 문서 내용과 이미지 글자는 뒤에서 차례로 읽고, 읽은 파일부터 바로 검색됩니다.

회사 메일도 연결되나요?

IMAP 또는 POP3를 지원하는 메일(메일플러그, 네이버, 다음, Gmail 등)을 연결할 수 있습니다. 서비스에 따라 앱 비밀번호가 필요합니다. Microsoft 365처럼 IMAP이 막힌 회사 메일은 지금은 연결할 수 없습니다. 찾은 메일은 앱 안에서 바로 보고, 첨부파일도 열거나 저장할 수 있습니다.

검색 결과를 누르면 어떻게 열리나요?

한글·워드·엑셀·파워포인트 문서는 PC에 설치된 그 프로그램에서 찾은 쪽·셀·슬라이드로 바로 열리고 찾은 문구가 선택됩니다. PDF는 Adobe Acrobat(Reader)이 있으면 그 쪽으로 열리고, 없으면 FindInside 안의 PDF 보기로 그 쪽을 엽니다. 텍스트 파일은 앱 안 미리보기에서 그 줄을 보여 줍니다. 해당 프로그램이 없으면 기본 프로그램으로 파일을 열고 찾을 문구를 복사해 두니 Ctrl+F → Ctrl+V로 찾으면 됩니다.

PC가 느려지지 않나요?

내용 읽기는 낮은 우선순위로 뒤에서 하고, 한 번 읽은 파일은 바뀌지 않는 한 다시 읽지 않습니다.

라이선스 키는 어디에 넣나요?

앱 위쪽의 "라이선스 키 입력" 버튼(체험 기간이 끝났으면 가운데 안내의 버튼)을 누르거나, 메뉴 도움말 → 라이선스를 엽니다. 구매 확인 메일의 키를 붙여 넣고 활성화를 누르세요. 인터넷이 연결되어 있어야 합니다.

설치 파일(.exe)을 받을 때 경고가 떠요.

Microsoft Store에서 받으면 경고 없이 설치됩니다. 설치 파일을 직접 받으면 새로 나온 프로그램이라 Windows와 브라우저가 한 번 확인하는 창입니다. Edge에서 "{{SETUP_FILE}}은(는) 일반적으로 다운로드되지 않습니다"가 뜨면 오른쪽 ⋯ → 유지 → 그래도 계속을 누르세요. 설치 파일을 실행할 때 "Windows의 PC 보호"(PC를 보호했습니다) 창이 뜨면 추가 정보 → 실행을 누르면 설치됩니다.

체험 기간이 끝나면 색인한 자료가 지워지나요?

아니요. 색인은 그대로 남아 있고, 라이선스 키를 넣으면 바로 다시 검색할 수 있습니다.

V3에서 "앱 격리 검사"가 떠요.

설치 파일(.exe)을 직접 받으면 백신이 새 프로그램을 먼저 검사합니다. 검사가 끝날 때까지(최대 몇 분) 기다리면 됩니다. Microsoft Store에서 받으면 이 검사 없이 바로 설치됩니다.

PC를 바꾸면 어떻게 하나요?

쓰던 PC에서 도움말 → 라이선스 → "이 PC에서 해제"를 누른 뒤, 새 PC에서 같은 키를 입력하면 됩니다.

환불은 어떻게 하나요?

구매 후 {{REFUND_DAYS}}일 안에 구매 확인 메일의 링크나 아래 문의처로 요청하시면 전액 환불해 드립니다.
