# FindInside

FindInside는 Windows PC의 로컬 파일, 이메일, 이메일 첨부파일, 저장된 메일 파일과 음성 녹음을 한곳에서 찾는 **Local-First 통합 검색·수집 프로그램**입니다.

파일명을 정확히 몰라도 문서와 메일의 내부 내용, 경로, 메타데이터와 의미적 유사성을 이용해 필요한 자료를 찾는 것이 목표입니다. Everything을 대체하기보다, 파일명·경로 검색을 넘어 내용 기반 탐색이 필요할 때 함께 사용하는 제품을 지향합니다.

## 핵심 기능

- 로컬 파일, 이메일, 첨부파일, MSG/EML, M4A 통합 검색
- 키워드·정확 검색과 의미 검색 결합
- 다중 검색어와 `AND` / `OR` / `NOT` / 구문 검색
- 경로, 형식, 날짜, 메일 조건 필터 및 결과 내 재검색
- 선택 폴더 색인, 제외 폴더, 증분 색인
- 문서 페이지·시트·셀·슬라이드·문단과 음성 타임스탬프 표시
- 결과별 검색 근거와 관련도 설명
- `관련 있음` / `관련 없음` / `보류` 육안 검수
- 논리적 수집 및 지정 폴더로 실제 파일 복사

## v1 지원 대상

- 문서: HWP, HWPX, DOC, DOCX, XLS, XLSX, PPT, PPTX, PDF, TXT, CSV
- 메일: Microsoft 365 / Outlook, 범용 IMAP, MSG, EML
- 음성: M4A 음성 인식(STT)
- 플랫폼: Windows 설치형 앱 (`Find_Setup.exe`)

Windows PC 앱이 색인과 검색 엔진의 중심이고, Android/iOS 앱은 PC와 연결해 검색 결과 확인·검수·수집을 담당합니다.

## 제품 원칙

- **Local-First:** 회사 문서, 고객자료, 서버 정보 등 민감한 자료의 분석과 색인을 기본적으로 PC 내부에서 처리합니다.
- **설명 가능한 결과:** 관련도 숫자만 보여주지 않고 결과가 검색된 근거와 내부 위치를 함께 표시합니다.
- **사람의 최종 판단:** AI가 자료를 자동으로 정답 처리하지 않으며 사용자가 후보를 검수합니다.
- **원본 보호:** 원본 파일을 기본적으로 이동하거나 삭제하지 않습니다.
